# GT OSPO co-branding assets

`gt-ospo-navy.png` is the supplied `Open Source Program Office_Navy cropped.png`.
`gt-ospo-white.png` is the supplied `Open Source Program Office_White.png`.
Both files are copied unchanged from the GT OSPO assets provided for this design.
The original supplied files remain unchanged.

The public header places GT OSPO beside the existing DARE lockup and retains
“A Carnegie Mellon University Project.” The footer retains the DARE mark and
“Powered by DARE” attribution with the OFAI / CMU Libraries descriptor.

The institutional arrangement is a local design proposal while the team discusses
co-branding with CMU. Do not describe this implementation as confirmation of a
partnership agreement. See the [DARE brand guidelines](https://dare.cmu.edu/docs/reference/brand/)
for the distinction between community and partner deployments.

`gt-ospo-navy-bold.png` is a separate header variant with heavier lettering, requested for the GT site. It is a derived asset, not an unchanged official logo file. The header presents the same variant in white in dark mode using a display filter. Keep the supplied originals above for reference or restoration.
